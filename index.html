Open source

Health data standards and clinical text tooling.

Two projects, published openly under the Apache License 2.0: a data model for observational health records collected in Egypt, and a deterministic tool for analysing clinical text against controlled terminologies.

Projects

EMOP

Egyptian Medical Observational Profile

A relational data model for observational health records in Egypt. Covers national identifiers, the 27 governorates, public and military insurance schemes, referrals between facilities, and national code lists mapped to standard concepts.

Documentation Repository

COE

Corpus Ontology Enricher

An offline system that matches phrases in clinical text to pinned terminology releases and reports coding frequency, mention context, unmapped candidate terms, and code co-occurrence — with privacy controls applied before anything leaves the process.

Documentation Repository

Approach

Standards first
Both projects build on established specifications rather than replacing them, and document exactly where they diverge.
Explicit provenance
Every code carries its source and status. Illustrative data is labelled as such and never presented as an official release.
Reproducible
Deterministic, offline execution. Schema and analysis outputs can be rebuilt from pinned inputs.
Privacy by construction
No patient data in either repository. Licensed terminology payloads are kept out of public source control.
