Egyptian health data standards, published in the open.

معايير البيانات الصحية المصرية

Two public artefacts. EMOP is a data model for observational records collected in Egypt. COE is a tool that reads clinical text against pinned terminologies. Both live on GitHub under Gehad Sayed Ahmed.

EMOP

النموذج المصري للبيانات الطبية الرصدية

OMOP table names, plus Egyptian tables for national ID, governorates, UHIA and HIO, civil and military care, referrals, and bilingual names.

EMOP documentation

COE

Corpus Ontology Enricher

Offline phrase-to-code analysis with mention context, a synthetic demo, and a hard split between public code and licensed terminology indexes.
