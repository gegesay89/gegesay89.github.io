COE

An offline system that reads a fixed snapshot of clinical text, matches phrases to pinned terminology releases, and reports what was coded, in what context, and what could not be matched at all.

Mention context

Each mention receives exactly one context label, so a ruled-out diagnosis or a relative's illness is never counted as a current finding.

LabelMeaning
current_clinicalAffirmed, about the patient, present
negatedThe text asserts the concept is absent
non_patientThe mention belongs to a family member or other person
historicalThe patient's past rather than the present

Precedence runs negated, then non-patient, then historical, then current. Scope is bounded by sentence, word distance, conjunctions that break scope, and record section headers. This is a conservative screen over text, not a full grammatical parser.

What a run produces

  • Coding frequency for phrases that resolve to exactly one code
  • Per-system counts where a phrase was ambiguous
  • The context breakdown behind every code
  • Surface forms observed in the text, as synonym evidence
  • Ranked frequent terms that matched no code at all
  • Code co-occurrence pairs scored for association strength
  • A run report carrying provenance, privacy counters, and hashes

Privacy controls

  • Rows appearing in too few documents are suppressed and reported only as counts
  • Text carrying long digit runs, contact markers, or excessive length is rejected before it can leave the process
  • Documents with unusually many codes are excluded from association counting

Getting started

Licensed terminologies are not distributed here. The public repository contains code, schemas, and a synthetic demonstration set with no patient data. Reference indexes are built locally on a machine that already holds the licensed files. 
git clone https://github.com/gegesay89/coe-corpus-ontology-enricher.git
cd coe-corpus-ontology-enricher
uv sync --extra dev
uv run coe demo create demo
uv run pytest

The demonstration profile is a deterministic slice used for regression testing, including a completable review workflow recorded as an append-only, hash-chained decision log.

Scope

COE is not a publication system and not a clinical decision system. Candidate evidence is not acceptance, coding counts are evidence about a body of text rather than clinical prevalence, and association rows describe co-mention rather than any clinical relationship.
