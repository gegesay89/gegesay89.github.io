COE

Corpus Ontology Enricher

An offline system that reads a clinical-text snapshot, matches phrases to pinned terminology releases, and writes coding counts, mention context, unmapped terms, and co-occurrence rows. It is not a publication system and not a clinical decision system.

GitHub repository Install and demo Apache 2.0
Licensed terminology payloads (SNOMED, CPT, RxNorm, and the rest) are not in the public repository. The public tree is code, schemas, and a PHI-free synthetic demo. Build private indexes on a machine that already holds the licensed files.

What a run produces

Mention context is split so a negated or family-history mention is not counted as a current finding: current_clinical, negated, non_patient, historical.

Matching is exact-first with a small set of deterministic variants. Every emitted code must exist in the pinned release.

Synthetic demo

Python 3.11 or newer, and uv:

uv sync --extra dev
uv run coe demo create demo
uv run pytest
