EMOP

A relational data model for observational health records collected in Egypt. It extends an established international model with the facts Egyptian care actually records, and documents how to translate back for international research.

Egyptian tables

These sit alongside the international core rather than replacing any part of it, so nothing has to be squeezed into a field that was designed for another health system.

Example data

Illustrative codes only. Every invented clinical or tariff code in this release is prefixed EX- and flagged in the data. None of it comes from the Ministry of Health, the Universal Health Insurance Authority, or the Health Insurance Organization. Governorate codes are the ISO geographic standard, not a clinical terminology.

What ships

  • Complete schema definitions with primary keys, foreign keys, and indexes
  • Reference data for governorates, insurance schemes, and care sectors
  • Small example code lists with mappings to standard concepts
  • One fictional patient journey: primary care visit, referral, hospital visit, diagnosis, prescription

Install

git clone https://github.com/gegesay89/emop.git
cd emop
createdb emop
./ddl/install.sh postgres://localhost/emop
psql postgres://localhost/emop -f vocabulary/load_examples.sql
psql postgres://localhost/emop -f examples/toy_egypt.sql

This produces 52 tables and 194 foreign keys. Applying the international foreign-key and index files is covered in the repository, including the order to follow when loading a full standard vocabulary.
