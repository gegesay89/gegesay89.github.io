EMOP

النموذج المصري للبيانات الطبية الرصدية

An Egyptian profile of the Observational Medical Outcomes Partnership common data model. The core keeps OMOP 5.4 names. Egypt is modelled as extra tables, not as renamed OMOP tables.

GitHub repository Table list Crosswalk to OMOP Apache 2.0
Example clinical and tariff codes in the repository use an EX- prefix. They are not official Ministry of Health, UHIA, or HIO codes. Governorate codes are ISO 3166-2:EG.

Core, unchanged

PERSON, VISIT_OCCURRENCE, CONDITION_OCCURRENCE, DRUG_EXPOSURE, and the rest of OMOP 5.4 sit in schema emop with their original columns. That layout is OHDSI’s, vendored under Apache 2.0.

Install

PostgreSQL 14 or newer. Clone the repository and run ./ddl/install.sh. Instructions and the Athena caveat are in the repository README.
